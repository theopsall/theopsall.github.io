# src/components/ui/ — Vendored shadcn/ui Primitives

## Do not hand-edit

Files in this directory are generated by the shadcn CLI. Editing them manually will be overwritten on the next `add` or `diff` run and causes divergence from upstream.

## To add a new primitive

1. Query context7 for the current command:
   ```
   mcp__plugin_context7_context7__resolve-library-id("shadcn/ui")
   mcp__plugin_context7_context7__query-docs → "install <component-name> CLI command"
   ```
2. Run from the project root:
   ```bash
   npx shadcn@latest add <name>
   ```
3. Commit the generated file as-is. Do not modify it.

## To update an existing primitive

```bash
npx shadcn@latest diff   # see what changed upstream
npx shadcn@latest add <name> --overwrite
```

## Naming convention

Filenames here are **kebab-case** (shadcn convention, e.g. `scroll-area.tsx`). This is intentional and differs from the `PascalCase` directory convention used for our own components. Do not rename them.

## Importing

```ts
import { Button } from '@/components/ui/button';
import { ScrollArea } from '@/components/ui/scroll-area';
```
