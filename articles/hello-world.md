# Hello World

Welcome to my blog! This is the first post on my terminal portfolio.

## About This Blog

I built this blog directly into my terminal portfolio. Articles are rendered as **Markdown** in separate tabs — just like a real terminal emulator.

### Why a Terminal Blog?

- It fits the aesthetic of the portfolio
- Markdown is a natural format for technical writing
- Tabs make it easy to switch between the shell and articles

## Code Example

Here's a quick TypeScript snippet:

```typescript
const greet = (name: string): string => {
  return `Hello, ${name}! Welcome to my blog.`;
};

console.log(greet("World"));
```
